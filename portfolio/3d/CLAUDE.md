# 3D-мастер Arvis — правила

Ты делаешь одну 3D-сцену для сайтов студии Arvis. Сцена — это один файл `models/<id>.js` (ES-модуль), который подключается любым сайтом через `stage.js`. Посмотри образцы: `models/donut.js`, `models/particles.js`, `models/bloom.js`, `models/gears.js`, `models/gem.js`, `models/silk.js` — делай не хуже.

## Контракт модуля (обязательно)

```js
export const meta = {
  id: 'имя-файла-без-.js', name: 'Назва українською', for: 'для кого: типи бізнесу через кому',
  idea: 'Одне-два речення українською: що видно і що відбувається, поки гортаєш.',
  colors: ['#основний', '#ще', '#ще'], color: '#основний',
  // scale: 0.8, z: 7.5 — за потреби: розмір і відстань камери
};
export function create(THREE, { weak = false, color = meta.color } = {}) {
  // зібрати сцену з коду; повернути:
  return {
    object,                 // THREE.Group — усе в ній, центр сцени в (0,0,0), уміщається в коло радіусом ~2.2
    update(f) {},           // f = { t, dt, p, mx, my, weak, instant } — кожен кадр
    setColor(hex) {},       // плавна зміна головного кольору
    dispose() {},           // звільнити геометрії й матеріали
  };
}
```

- `p` (0..1) — прогрес прокрутки сторінки. **Сцена має помітно змінюватися від p**: розкриватися, збиратися з частинок, розбиратися на шари, перетворюватися, змінювати форму. Просто «обертається» — мало.
- `mx`, `my` (−0.5..0.5) — курсор/палець: легкий нахил чи реакція.
- `instant` — true при скриншотах: стан одразу дорівнює `p`, без плавного доганяння. Пиши так: `shown = instant ? p : shown + (p - shown) * Math.min(1, dt * 3)`.
- `weak` — слабкий телефон: менше частинок/сегментів (приблизно вдвічі).

## Можна і не можна

- Тільки `THREE` з параметра (three.js r160, ліцензія MIT). Жодних інших бібліотек, `import` з інтернету, файлів моделей (.glb/.obj), картинок і шрифтів ззовні. Усе — з коду: геометрії Three, свої BufferGeometry, ExtrudeGeometry, LatheGeometry, InstancedMesh, Points, CanvasTexture для простих спрайтів.
- Матеріали — MeshStandardMaterial / MeshPhysicalMaterial (оточення для відблисків уже дає stage.js). Не використовуй `transmission` — на багатьох телефонах виглядає як біла пляма.
- Не гальмувати: до ~150 тис. трикутників, до ~8 тис. частинок, однакові дрібні об'єкти — через InstancedMesh, не створюй нові об'єкти в `update`, не викликай `computeVertexNormals` на сітці більше ~15 тис. вершин кожен кадр.
- Стиль: без кислотного неону й «свічення» — красиві матеріали, світло, форма. Сцена має виглядати як зроблена дизайнером, а не як демка.
- Коментарі в коді — українською, коротко.
- Не чіпай інші файли: тільки свій `models/<id>.js`.
