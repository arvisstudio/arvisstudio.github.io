# Дизайнер Arvis — правила для сайтів портфоліо

Ти робиш один концепт-сайт для портфоліо студії Arvis за ідеєю фантазера (`concept.json` у поточній папці). Мета — щоб власник бізнесу відкрив з телефона й сказав «вау, хочу такий». Планка — `glazur/index.html` (3D-пончик летить сторінкою): подивись його перед роботою.

## Що зробити

Один файл `index.html` у поточній папці (усе в ньому: CSS у `<style>`, JS у `<script>`). Інших файлів не створюй, нічого поза папкою не змінюй.

## Обов'язково

- Мова сайту — українська. Назва — з концепту.
- Перша плашка: `Концепт-сайт від <b>Arvis</b>: такого закладу немає, це приклад нашої роботи. <a href="https://t.me/arvisstudio_bot">Хочу такий сайт</a>`.
- У `<head>`: `<meta name="robots" content="noindex">`, viewport, `<title>`, og:title/og:description.
- Внизу: `Сайт зроблено командою <a href="https://arvisstudio.github.io">Arvis</a>`.
- Скрипт на початку `<head>`: `<script>if (!/still/.test(location.search)) document.documentElement.classList.add("js")</script>` — анімації появи вмикай тільки під `.js` (для скриншотів з `?still` усе має бути видно одразу).
- Не вигадувати: відгуки, рейтинги, «з 2010 року», імена людей, адреси й телефони — НЕ можна. Замість них чесно: «Тут будуть відгуки ваших гостей», «Тут буде ваша адреса», «Тут буде ваш номер». Ціни — з підписом «Приклад цін».
- Одна справжня корисна функція для бізнесу (як кошик із часом, онлайн-запис, калькулятор, збирання коробки) — з концепту. Кнопка «Замовити/Записатися» показує чесне повідомлення «Це концепт: на справжньому сайті заявка прийде в Telegram».

## Як має виглядати і рухатись

- Не слайди! Розділи перетікають один в одний: спільний фон, що змінює колір, об'єкт, що летить між розділами, sticky-сцени, текст, що їде поверх фото, величезні слова на фоні, плавна поява блоків.
- 3D (якщо в концепті): підключай сцену з бібліотеки `../3d/models/<id>.js` через `../3d/stage.js` (див. `../3d/CLAUDE.md` і `glazur/index.html`), importmap з three@0.160.0 з cdn.jsdelivr.net. Канвас — `position: fixed` позаду тексту, `pointer-events: none`. `progress` — частка прокрутки сторінки або розділу.
- Шрифти — Google Fonts з кирилицею, не більше двох. Без неону, фіолетових градієнтів, «скла» й однакових карток з тінями — це виглядає як нейросітка.
- Антислоп (бот перевіряє автоматично, жорстка прикмета = оцінка не вище 7): фіолетові градієнти, градієнтний текст (background-clip:text), «скло» (backdrop-filter: blur), неонові кольори й холодне світіння (кольорова тінь 0 0 30px), емодзі замість іконок — малюй прості SVG. М'яко: шрифт Inter/Poppins основним, рекламні штампи («новий рівень», «безшовний»), однаковий радіус і тінь на кожній картці. Тепле світло там, де справді світиться (лампа, вогонь), — можна.
- Фото: тільки з `../../demo/_photos/` (див. `../../demo/_photos/photos.json`) або без фото. Нічого з інтернету.
- Спершу телефон (375 px), потім комп'ютер (1440 px). Текст ≥ 16 px, кнопки ≥ 44 px. Текст ніде не налазить на текст і не ховається під 3D. Жодної горизонтальної прокрутки (`grid-template-columns: minmax(0, 1fr)`, `overflow-x: hidden`).
- Швидкість: анімації через `transform`/`opacity`, `requestAnimationFrame`, `passive` слухачі прокрутки; `prefers-reduced-motion` — усе статично.
- Розмір `index.html` — до 70 КБ.

Коли закінчиш — просто збережи `index.html`. Скриншоти, перевірку й публікацію зробить бот.
