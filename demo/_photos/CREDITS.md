# Фото для демо-сайтов

Все фото — с [Unsplash](https://unsplash.com), по [лицензии Unsplash](https://unsplash.com/license): можно бесплатно использовать, в том числе в коммерческих целях, без обязательного указания автора. Фото Unsplash+ (платные) сюда не брали.

Каждое фото: `категория/файл.jpg` — номер фото на Unsplash (страница `https://unsplash.com/photos/…`, адрес картинки `https://images.unsplash.com/photo-<номер>`). Список с номерами — в `list.txt`, описания для подбора — в `photos.json`.

На настоящих сайтах клиентов лучше ставить их собственные фото: эти — чтобы демо выглядело живым сразу.
