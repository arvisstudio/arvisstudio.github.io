# Демо-сайты Arvis — правила для Claude

Ты делаешь демо-сайт для конкретного заведения: менеджер студии Arvis стоит у владельца и через минуту-две покажет ему этот сайт на телефоне. Задача сайта — чтобы владелец сказал «хочу такой». Если сайт выглядит как шаблон или как список — он просто уйдёт.

## Что у тебя есть

- `brief.json` в текущей папке — что сказал менеджер: название, тип, адрес, телефон, меню/услуги с ценами, пара слов о заведении, список фото.
- `img/` в текущей папке — фото, которые менеджер снял в заведении (если есть). Они важнее всего: это ИХ вход, зал, блюда.
- `../_photos/photos.json` — библиотека бесплатных фото (кофе, десерты, еда, хлеб, интерьеры, цветы, салоны, магазины) с описаниями и тегами. Путь к фото на странице: `../_photos/<file>`.

Сделай ОДИН файл: `index.html` в текущей папке. Других файлов не создавай и ничего вне текущей папки не меняй.

## Обязательно

- Язык сайта — украинский. Название заведения — как в брифе, без изменений.
- Первая строка страницы — тонкая чёрная плашка: `Це демо-сайт від <b>Arvis</b> — так може виглядати сайт «НАЗВА». <a href="https://t.me/yyfvjk">Замовити</a>`.
- В `<head>`: `<meta name="robots" content="noindex">`, `<meta name="viewport" content="width=device-width, initial-scale=1">`, `<title>НАЗВА — …</title>`.
- Внизу: `Сайт зроблено командою <a href="https://arvisstudio.github.io">Arvis</a>`.
- Всё в одном файле: CSS внутри `<style>`, JS — только если правда нужен (вкладки меню), без библиотек. Шрифты — Google Fonts с кириллицей.
- Только картинки из `img/` и `../_photos/`. Никаких ссылок на чужие картинки в интернете.

## Нельзя выдумывать

- Отзывы, рейтинги, награды, «с 2010 года», количество клиентов — НЕЛЬЗЯ. Владелец сразу увидит неправду. Блок отзывов можно, но с честной подписью: «Тут будуть відгуки ваших гостей».
- Цены — только из брифа. Меню не дали — поставь 4–6 типичных позиций для такого заведения с обычными для маленького города ценами и подписью «Приклад меню — тут будуть ваші позиції з цінами». Не оставляй цену пустой и не пиши «— ₴»: это выглядит как ошибка.
- Часы работы, доставка, Instagram — только если есть в брифе; иначе «Пн–Нд 8:00–21:00» с пометкой «(приклад)».

## Как должно выглядеть

Цель — как сайт хорошего местного заведения, сделанный дизайнером: тёплый, «вкусный», живой.

1. **Шапка**: название (логотип текстом), короткое меню-якоря (Меню · Про нас · Контакти) и кнопка «Зателефонувати» (если есть телефон).
2. **Первый экран**: большое фото на всю ширину (лучшее фото менеджера, иначе подходящее из библиотеки), название крупно, одна фраза про заведение (по брифу, без выдумки), кнопки «Замовити / Зателефонувати» и «Як дістатися» (Google Maps по адресу).
3. **Меню / товари / послуги**: карточки с фото, названием и ценой (₴). К каждой позиции подбери фото по смыслу из `photos.json` (капучино → чашка капучино, круасан → круасан); если подходящего нет — карточка без фото, но аккуратная. Позиций много — разбей по группам (Кава, Десерти, Сніданки…).
4. **Про нас**: 2–3 тёплых предложения по брифу + фото зала/входа.
5. **Галерея**: 4–6 фото (сначала из `img/`).
6. **Чому до нас**: 3 коротких пункта, только то, что следует из брифа или из самого типа заведения без конкретных цифр (например: «Свіжа випічка щодня» для пекарни — да; «Найкраща кава в місті» — нет).
7. **Відгуки**: заготовка с честной подписью (см. выше).
8. **Контакти**: адрес, телефон (кликабельный `tel:`), часы, карта Google Maps `<iframe src="https://maps.google.com/maps?q=АДРЕС&output=embed">` (если есть адрес). В адресе нет города — для карты и «Як дістатися» добавь «, Золотоноша» (иначе карта покажет Киев).
9. На телефоне — закреплённая внизу кнопка «Зателефонувати» (если есть телефон). Она появляется только после первого экрана (маленький JS: IntersectionObserver на первом экране) — там уже есть своя кнопка; и внизу страницы оставь отступ, чтобы она не закрывала контакты и подвал.

## Дизайн

- Сначала думай про это заведение: кофейня — тёплые кофейные тона и уют; цветочный — свежесть и много воздуха; барбершоп — тёмный, мужской; салон — светлый, нежный. Палитру и шрифты выбирай под него.
- Шрифты с кириллицей: заголовки — Playfair Display, Lora, Prata, Cormorant Garamond, Unbounded или Montserrat Alternates; текст — Manrope, Inter, Rubik или Nunito. Не больше двух.
- НЕ делать: неоновые цвета, фиолетовые градиенты, свечения, «стекло», одинаковые карточки с тенями на всём подряд, маленькие подписи КАПСОМ над каждым заголовком («МЕНЮ», «ПРО НАС» — заголовок и так понятен). Это выглядит как сайт, сделанный нейросетью.
- Иконки (телефон, адрес, часы) — простые линейные SVG прямо в коде, одного стиля. Эмодзи на сайте не использовать.
- Фото — главное украшение: `object-fit: cover`, скругления умеренные, `loading="lazy"` для всех, кроме первого экрана.
- Сначала мобильная версия (ширина 375 px), потом компьютер (1280 px). Текст не меньше 16 px, кнопки высотой от 48 px.
- Размер `index.html` — до 60 КБ.

Когда закончишь — просто сохрани `index.html`. Проверять в браузере и публиковать не нужно: это сделает бот.
